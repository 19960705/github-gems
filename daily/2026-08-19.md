- [unStone/web-ppt](https://github.com/unStone/web-ppt) 星标数1 · TypeScript · 创建于 2026-08-18

🛠 可衍生：只做 `.pptx`→SVG 的转换 API 服务，配 LibreOffice 对照校验，做成文档系统通用的"PPT 预览图生成"；或做"演示文稿差异对比器"——渲染两版 PPT 的 SVG 逐页 diff，给团队做评审工具。

- [MazzaWill/code-agent-board](https://github.com/MazzaWill/code-agent-board) 星标数1 · JavaScript · 创建于 2026-08-19
让两个**不同厂商**的 AI CLI（如 Codex vs Grok）独立审查你的未提交 diff，然后多轮辩论直到双方都没有 blocking objection，你在中间当主席逐条裁决。核心洞察：同一模型审查自己的输出会带着同样的盲点，跨厂商辩论才能暴露真问题；每轮只把结果表写进上下文，完整 transcript 落盘。
🛠 可衍生：做个只针对 `.env`/密钥/删除等敏感操作的"双模型强制辩论"守卫，任何 AI 改文件前先过一轮辩论；或简化成"单命令双模型 diff 审查"CLI，输出合并审查报告，差异点在裁决规则可配置。
